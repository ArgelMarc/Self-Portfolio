# Personal Portfolio

A responsive personal portfolio website made as the **Final Project for IT ELEC 4 – Web Systems and Technologies 2** at La Consolacion University Philippines (1st Semester, S.Y. 2026–2027).

🔗 **Live site:** https://your-portfolio.vercel.app *(replace after deploying)*

## 📄 Sections

| # | Section | Contents |
|---|---------|----------|
| 1 | **Home** | Name, professional introduction, animated tagline, social links |
| 2 | **About Me** | Personal introduction, info list, educational background timeline |
| 3 | **Skills** | Technical skills with animated progress bars and soft skills |
| 4 | **Projects** | Three project cards with category filter |
| 5 | **Achievements** | Certificates, awards, seminars and accomplishments |
| 6 | **Contact Me** | Email, phone, LinkedIn, GitHub and a validated contact form |

## ✨ Features

- Fully responsive layout for desktop, tablet and mobile
- Sticky navigation bar with active-section highlighting and smooth scrolling
- Mobile hamburger menu
- Dark / light mode toggle (remembers your choice)
- Scroll-reveal animations and a typing-effect tagline
- Project category filter
- Contact form with client-side validation (opens the visitor's email app)
- Back-to-top button

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Grid, custom properties, media queries)
- Vanilla JavaScript
- Google Fonts (Poppins & Inter)
- Deployed on [Vercel](https://vercel.com)

## 🚀 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/personal-portfolio.git
   ```
2. Open `index.html` in your browser — no build step needed.

## ☁️ Deployment (Vercel)

1. Push this repository to GitHub (public).
2. Sign in to [Vercel](https://vercel.com) with your GitHub account.
3. Click **Add New → Project** and import `personal-portfolio`.
4. Keep the defaults (Framework Preset: **Other**, no build command) and click **Deploy**.
